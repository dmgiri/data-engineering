# Public candidate-reported question batches

Each JSON entry points to the primary body of a direct public LinkedIn post describing an interview. These are author reports, not independently verified interview transcripts. `reported-question` means a specific question/scenario was given; `reported-topic` means the post named a subject/concept and the study question is a paraphrased prompt about that concept.

Answers and code are independently written study explanations, with separate official technical references. Do not attribute them to the candidate or company. Preserve null employer/experience/role fields when unknown. Do not add generic preparation lists, recommended-post content under the wrong permalink, invented experience details, or generated filler to meet the research target.
